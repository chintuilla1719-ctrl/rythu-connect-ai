# Code of Conduct

## Our Pledge

We are committed to creating a welcoming and inclusive environment for everyone.

## Expected Behavior

- Be respectful and professional.
- Use inclusive language.
- Accept constructive feedback.
- Collaborate openly and honestly.

## Unacceptable Behavior

- Harassment or discrimination.
- Offensive comments or personal attacks.
- Any behavior that creates an unsafe environment.

## Enforcement

Project maintainers may remove comments, commits, or contributions that violate this code of conduct.
