# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Rythu Connect AI, please report it responsibly to the project maintainers.

Please include:

* Description of the issue
* Steps to reproduce
* Potential impact
* Suggested fix (if available)

We will review and address valid security reports as quickly as possible.

## Supported Versions

Currently, the latest version of the project is supported for security updates.
