# Rythu Connect AI - User Manual

## 1. Introduction

Rythu Connect AI is an intelligent agricultural assistance platform designed to support farmers by providing crop recommendations, disease detection, weather forecasts, market price information, and farming guidance. The platform uses Artificial Intelligence and Data Analytics to help farmers make better decisions and improve agricultural productivity.

---

## 2. Purpose of the Application

The purpose of Rythu Connect AI is to:

* Help farmers select suitable crops.
* Detect crop diseases at an early stage.
* Provide weather-related information.
* Display current market prices of crops.
* Offer agricultural guidance and recommendations.

---

## 3. System Requirements

### Hardware Requirements

* Laptop/Desktop Computer
* Smartphone (Optional)
* Stable Internet Connection

### Software Requirements

* Windows/Linux/macOS
* Google Chrome, Microsoft Edge, or Mozilla Firefox
* Node.js and npm

---

## 4. Features

### Crop Recommendation

Provides crop suggestions based on:

* Soil Type
* Temperature
* Rainfall
* Humidity

### Disease Detection

Allows users to upload crop images and identify diseases affecting plants.

### Weather Forecast

Provides:

* Current Temperature
* Humidity Levels
* Rainfall Predictions
* Weather Alerts

### Market Price Information

Displays current market prices of agricultural products.

### Farmer Assistance

Provides answers and suggestions related to farming practices.

## 5. Installation Guide

### Step 1: Clone the Repository

```bash
git clone <repository-url>
```

### Step 2: Open Project Folder

```bash
cd rythu-connect-ai
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Run the Application

```bash
npm start
```

### Step 5: Open Browser

Visit:

```text
http://localhost:5000
```

## 8. Using Crop Recommendation Module

### Steps

1. Open Crop Recommendation section.
2. Enter soil information.
3. Enter weather details.
4. Click Submit.
5. View recommended crops.

### Output

* Recommended Crop Names
* Suitability Information
* Farming Suggestions

---

## 9. Using Disease Detection Module

### Steps

1. Open Disease Detection.
2. Upload crop or leaf image.
3. Click Analyze.
4. Wait for processing.
5. View disease prediction results.

### Output

* Disease Name
* Confidence Score
* Suggested Treatment

---

## 10. Using Weather Information Module

## 12. Troubleshooting

### Application Not Opening

Possible Causes:

* Internet connection issue
* Server not running

Solution:

* Check network connection.
* Restart application.

### Login Failed

Possible Causes:

* Incorrect username
* Incorrect password

Solution:

* Verify credentials.
* Reset password if available.

### Data Not Loading

Possible Causes:

* API connection issue
* Server issue

Solution:

* Refresh page.
* Check server status.
